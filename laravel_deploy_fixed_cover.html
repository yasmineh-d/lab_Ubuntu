00
🗄️
Nginx
The web server. Receives HTTP requests, manages static files and security.
⚙️
PHP-FPM
The engine. Processes Laravel PHP code in the background for Nginx.
🔑
Permissions
The security. Ensures Nginx can write logs and cache files correctly.
01
Step
System
Prep
apt update
Update the package list and install the main servers before anything else.
Commands
sudo apt update sudo apt install nginx php-fpm -y
Refresh the repository list.
Install the Nginx binary.
Install the FastCGI Process Manager.
02
Step
Laravel
Extensions
php-fpm
Laravel needs specific PHP extensions for database, text, and security operations.
Install extensions
sudo apt install php-mysql php-mbstring \ php-xml php-bcmath php-curl php-zip -y
PDO
Database connection
Mbstring
Text processing
XML / JSON
Data format support
BCMath
Precision arithmetic
03
Step
App
Deployment
/var/www
Place your Laravel project in the standard web directory /var/www/.
Move project
sudo mv ~/my-project /var/www/laravel-app
Create a clean project folder.
Move files from home to /var/www.
Use composer if installing fresh.
04
Step
Server
Block
nginx.conf
Create a config in /etc/nginx/sites-available/laravel. Point root to the public folder.
Nginx config
server { listen 80; server_name monprojet.local; root /var/www/laravel-app/public; index index.php; location / { try_files $uri $uri/ /index.php?$query_string; } }
05
Step
Enable
Site
symlink
Tell Nginx this site is enabled, check syntax, then reload the service.
Activate & reload
sudo ln -s /etc/nginx/sites-available/laravel \ /etc/nginx/sites-enabled/ sudo nginx -t sudo systemctl reload nginx
Link available to enabled sites.
nginx -t checks for syntax errors.
Reload applies changes without downtime.
06
Step
Folder
Permissions
www-data
Give www-data ownership and write access to the key folders.
Set permissions
sudo chown -R www-data:www-data /var/www/laravel-app sudo chmod -R 775 /var/www/laravel-app/storage sudo chmod -R 775 /var/www/laravel-app/bootstrap/cache
⚠ Without this, you will get a "Permission Denied" error.
07
Step
Final
Test
go live
Open your browser and navigate to your VM's IP or local URL.
Your URL
http://monprojet.local
If you see the Laravel logo — your deployment is successful!
